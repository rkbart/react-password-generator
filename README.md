🔐 Password Generator and Vault App
A full-stack password management application built with React (frontend) and Ruby on Rails (backend API), enabling users to securely generate, store, and manage their passwords.

🚀 Features
🔑 Secure Password Generator
Generate strong, customizable passwords with options for:
- Length
- Special characters
- Numbers
- Uppercase / lowercase letters

📋 One-Click Copying
Quickly copy generated passwords to clipboard.

🗄️ Password Vault
Save and organize passwords in a personal vault.

🔒 User Authentication
Token-based authentication using Devise.

🌐 RESTful API
Backend API built with Ruby on Rails and PostgreSQL for secure password storage and management.

📱 Responsive Design
Clean, responsive UI built with Tailwind CSS.

🔗 Frontend (React)	https://github.com/rkbart/react-password-generator
🔗 Backend (Rails API)	https://github.com/rkbart/password-api
